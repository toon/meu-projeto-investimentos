1. Modelo (src/models/NovaEntidade.js)
Define a estrutura no MongoDB. 

Se for Global (ex: ClasseAtivo, Corretora): Não precisa de vínculo de portfólio. 

Se for Tenant/Local (ex: CategoriaAtivo, Investidor): DEVE ter idPortfolio. 


Registo no Barrel: Adiciona ao src/models/index.js. 

2. Validador (src/validators/novaEntidadeValidator.js)
Usa o Zod para criar o contrato de dados.

Define campos obrigatórios, tipos e mensagens de erro amigáveis.


Registo no Barrel: Adiciona ao src/validators/index.js. 

3. Serviço (src/services/novaEntidadeService.js)
Contém a lógica de persistência pura. 

Não deve tocar em req ou res. 


Registo no Barrel: Adiciona ao src/services/index.js. 

4. Controlador (src/controllers/novaEntidadeController.js)
Atua como o maestro da requisição HTTP. 

Valida dados com o Zod. 

Verifica permissões com req.habilidades (CASL). 


Registo no Barrel: Adiciona ao src/controllers/index.js. 

5. Rotas (src/routes/novaEntidadeRoutes.js)
Define os endpoints e aplica os middlewares. 


Global: Usa autenticar e autorizacaoGlobal. 


Por Portfólio: Usa autenticar e autorizacaoPortfolio. 


Registo no Servidor: Liga o ficheiro ao prefixo correto no src/server.js. 

O Checklist do Erro "Undefined"
Se o servidor crashar com TypeError: Cannot read properties of undefined, verifica:


Chaves na Importação: Estás a usar { } num ficheiro que foi exportado com module.exports = nome (sem chaves)? 


Esquecimento no Barrel: Adicionaste o novo ficheiro ao index.js da pasta correspondente? 


Ficheiro Salvo: O VS Code está com a "bolinha branca" de arquivo não salvo?
